# 🎯 Wordageddon - Advanced Java Programming course project - Group 10

[![Java](https://img.shields.io/badge/Java-8-orange.svg)](https://www.oracle.com/java/)
[![JavaFX](https://img.shields.io/badge/JavaFX-white.svg)](https://openjfx.io/)
[![SQLite](https://img.shields.io/badge/SQLite-3-green.svg)](https://www.sqlite.org/)

- ⚙️ Advanced Java Programming team project, Academic Year 2024-25
- 🎓 Computer Engineering Bachelor's degree course, cohort 2022-23
- 🏫 Dept. of Information, Electrical Engineering and Applied Mathematics @ [University of Salerno](https://unisa.it/)

## ✨ Features

- **📚 Text Analysis Game** - Interactive word frequency analysis challenges
- **🎮 Multiple Difficulty Levels** - Easy, Medium, and Hard game modes
- **📊 Document Processing** - Advanced text mining and term frequency analysis
- **🏆 Scoring System** - Track your performance and compete on leaderboards
- **👨‍💼 Admin Panel** - Administrative interface for game management
- **📈 User Progress Tracking** - Monitor learning progress and statistics
- **🔒 User Authentication** - Secure login and registration system
- **🎯 Question Generation** - Dynamic question creation based on document analysis


## 🛠️ Tech Stack

- **Language**: Java 8
- **GUI Framework**: JavaFX
- **Database**: SQLite with JDBC
- **Architecture**: MVC (Model-View-Controller)
- **Build Tool**: Ant
